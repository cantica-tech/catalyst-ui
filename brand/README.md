# Brand assets

The app icons are the owner's flask (owner's confirmation, 2026-10-24, REQ-000066-UVqkd7cL): its licence is the
owner's own, so the UI still ships nothing of unknown licence (brand item 4). The brand's own mark (brand roadmap item
6; the `brand` roadmap and `docs/design/25-brand-spike.md`) will replace it.

| File                                                   | What               | Used as                                                           |
| ------------------------------------------------------ | ------------------ | ----------------------------------------------------------------- |
| `packages/catalyst-host-vscode/resources/icon.png`     | the flask, 256 px  | the Marketplace icon                                              |
| `packages/catalyst-host-vscode/resources/catalyst.svg` | the flask, vector  | the VS Code activity bar, the views and the `.catalyst` file icon |
| `packages/catalyst-host-electron/build/icon.png`       | the flask, 1024 px | the desktop app icon                                              |

`placeholder-mark.svg` and `placeholder-app-icon.svg` are the placeholder mark that stood in for it from 19 to 24 October
2026 (REQ-000059-UVqkd7cL); kept, unused.

The chain inspector's section and type icons are VS Code's own Codicons (`packages/catalyst-host-vscode/src/codicons.ts`);
the extension ships no icon files of its own.
